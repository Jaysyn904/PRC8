:: Spellsword Spellcasting (Fey) ::

Spells per Day: At every odd-numbered level, a spellsword gains new spells per day as if he had also gained a level in an arcane spellcasting class he belonged to before adding the prestige class. He does not, however, gain any other benefit a character of that class would have gained (metamagic or item creation feats, and so on), save for an increased effective level of spellcasting. If a character had more than one spellcasting class before becoming a spellsword, he must decide to which class he adds the new levels to for purposes of determining spells per day.

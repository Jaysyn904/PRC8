:: Havoc Mage Spellcasting (Suel Archanamach) ::

Spells per Day: At 2nd, 4th, and 5th level, a havoc mage gains new spells per day as if he had also gained a level in an arcane spellcasting class he belonged to before adding the prestige class. He does not, however, gain all the benefits a character of that class would have gained (metamagic or item creation feats, and so on), except for an increased effective level of spellcasting. If a character had more than one arcane spellcasting class before becoming a havoc mage, he must decide to which class he adds the levels to for purposes of determining spells per day.

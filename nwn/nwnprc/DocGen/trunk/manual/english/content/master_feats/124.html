:: Chose a Discipline (1st lvl) ::


Every Psion must decide at first level which discipline he will specialize in. Choosing a discipline provides a psion with access to the powers that are restricted to that discipline. If you try take a more than one psionic disipline, your character will be releveled. If you do this at first character level, you will need to delete the character and start over.

Egoist (Psychometabolism)
Kineticist (Psychokinesis)
Nomad (Psychoportation)
Seer (Clairsentience)
Shaper (Metacreativity)
Telepath (Telepathy)
